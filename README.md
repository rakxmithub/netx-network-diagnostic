## 🧠 About

<div align="center">
<img src="https://readme-typing-svg.demolab.com?font=JetBrains+Mono&weight=600&size=15&duration=1800&pause=600&color=00FF88&center=true&vCenter=true&width=950&height=40&lines=%3E+ONE+TOOL.+EVERY+NETWORK+ANSWER.;%3E+DESIGNED+FOR+SPEED%2C+CLARITY+AND+CONTROL.;%3E+NO+GUI.+NO+CLUTTER.+JUST+SIGNAL." alt="about animation"/>
</div>

**NetX** is a Python-based Windows network diagnostic and monitoring toolkit that brings every essential networking utility — Wi-Fi analysis, DNS benchmarking, ping monitoring, traceroute, and full system health scoring — into a single, fast, terminal-native application.

It wraps native Windows tools (`netsh`, `ipconfig`, `ping`, `tracert`) and Python's `socket` layer behind a clean, color-coded CLI so you get professional-grade diagnostics without opening five different apps.

<div align="center">

| 💡 Built for | 🎯 Solves |
|:---:|:---:|
| Sysadmins & Network Engineers | "Is it my Wi-Fi or my ISP?" |
| Developers debugging latency | "Why is my API suddenly slow?" |
| Power users & tinkerers | "What's actually on my network?" |
| Support & Helpdesk teams | "Give me a report I can attach to a ticket." |

</div>

## ⚙️ Installation

<table align="center">
<tr><td>

### `STEP 01` — Clone the repository
```bash
git clone https://github.com/rakxmithub/netx-network-diagnostic.git
```

### `STEP 02` — Enter the project directory
```bash
cd netx-network-diagnostic
```

### `STEP 03` — Install dependencies *(if any are listed in requirements.txt)*
```bash
pip install -r requirements.txt
```

### `STEP 04` — Run NetX
```bash
python main.py
```

> ⚠️ **Requirements:** Windows 10/11 · Python 3.8+ · Run as Administrator for full Wi-Fi profile & adapter access.

## ❓ FAQ

<details>
<summary><b>Does NetX need Administrator privileges?</b></summary>
<br>
Some modules (Wi-Fi profile passwords, certain adapter details) require running the terminal as Administrator on Windows. Most read-only diagnostics work without elevation.
</details>

<details>
<summary><b>Does NetX work on Linux or macOS?</b></summary>
<br>
Not yet — NetX currently relies on Windows-native tools (<code>netsh</code>, <code>ipconfig</code>, <code>tracert</code>). Cross-platform support is on the roadmap.
</details>

<details>
<summary><b>Where do exported reports go?</b></summary>
<br>
JSON reports are saved in the working directory as <code>netx_report_&lt;timestamp&gt;.json</code>.
</details>

<details>
<summary><b>Can I automate NetX (e.g. run it on a schedule)?</b></summary>
<br>
Yes — pair it with Windows Task Scheduler and the report export module to build a lightweight, unattended network health logger.
</details>
